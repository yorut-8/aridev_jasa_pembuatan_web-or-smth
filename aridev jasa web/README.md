# Website Paket Pembuatan Website · Aridev Studio

Etalase paket dan estimasi biaya pembuatan website dengan panel admin dan notifikasi email.

## Struktur
- `frontend/` : website (HTML, CSS, JavaScript murni). Dapat diunggah ke hosting statis.
- `backend/` : API Node.js untuk panel admin (edit harga) dan email notifikasi. Lihat `backend/README.md`.
- `docs/` : dokumentasi terpisah dari kode: SRS (.docx), panduan langkah demi langkah (.docx dan .html), diagram UML (`Diagram_UML` untuk draw.io, `Diagram_PNG` berupa gambar).

## Mulai cepat
1. Hanya website: buka `frontend/index.html` di peramban.
2. Dengan admin dan email: lihat `backend/README.md` (butuh Node.js 18+).

Catatan: dokumen di `docs/` menggambarkan versi website tanpa backend.
