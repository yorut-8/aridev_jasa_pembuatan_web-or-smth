Gambaran Umum dan Hasil Akhir

Panduan ini membawa Anda membuat website etalase paket pembuatan website: pengunjung bisa membandingkan tiga paket, menghitung estimasi biaya, lalu memesan lewat WhatsApp. Semuanya memakai HTML, CSS, dan JavaScript murni tanpa framework maupun server.

  • Katalog tiga paket (Basic, Business, Professional) dalam tampilan Grid dan Tabel.
  • Akordeon “Hasil akhir yang diterima” pada setiap paket.
  • Bar dan panel estimasi: jumlah proyek, opsi source code, dan revisi tambahan.
  • Pesan WhatsApp otomatis berisi paket dan estimasi harga.
  • Tema gelap yang warnanya bisa diganti dari satu berkas.
Siapkan editor teks (mis. Visual Studio Code), peramban modern, nomor WhatsApp studio, dan logo PNG transparan. Tidak ada yang perlu diinstal.

2

Menyiapkan Struktur Folder

Pisahkan berkas menurut tugasnya agar mudah dirawat: struktur di HTML, tampilan di CSS, data dan logika di JavaScript, serta gambar di folder tersendiri.

  • Buat folder paket-desain.
  • Di dalamnya buat folder css, js, dan images.
  • Buat berkas kosong index.html, css/theme.css, css/style.css, js/data.js, dan js/main.js.
  • Letakkan logo pada images/logo.png.
Hasil: satu berkas HTML dan tiga folder yang sudah berisi berkas-berkas kosong.

3

Membuat Kerangka Halaman

index.html hanya memuat struktur: navbar, hero, daftar paket, banner konsultasi, serta bar dan panel estimasi. Isi paket tidak ditulis di sini karena akan dibuat JavaScript dari data.

  • Tulis <head>: judul, viewport untuk ponsel, font Google, dan tautan ke dua berkas CSS.
  • Tulis navbar dan hero.
  • Tambahkan bagian #paket, banner #konsultasi, serta bar dan panel estimasi (langkah 9 dan 10).
  • Muat skrip di akhir <body>.
Urutan skrip penting: main.js memakai WA, D, dan X yang dibuat oleh data.js, jadi data.js harus dimuat lebih dulu.

4

Menentukan Tema Warna dan Font

Semua warna dan font disimpan sebagai variabel CSS di theme.css. Berkas CSS lain hanya memakai var(--nama), sehingga mengganti tema cukup dengan mengubah satu berkas.

  • Salin kode di bawah ke css/theme.css.
  • Ubah --ac untuk mengganti warna aksen (tombol dan sorotan).
  • Ubah --bg dan --card untuk mengganti latar halaman dan kartu.
  • Ganti --font-sans dan --font-serif bila memakai font lain, lalu muat fontnya di <head>.
Hasil: belum ada yang tampil, tetapi seluruh palet sudah siap dipakai.

5

Menulis Gaya Dasar dan Hero

style.css berisi tata letak. Mulai dari gaya dasar (reset, latar, wadah .wrap), lalu bagian hero dengan latar kotak-kotak halus.

  • Salin gaya dasar ke css/style.css, lalu lanjutkan dengan gaya navbar dan hero.
  • Perhatikan env(safe-area-inset-*) agar halaman tidak tertutup poni atau bilah sistem ponsel.
  • Pakai grid dua kolom pada hero dan satu kolom di layar kecil.
Hasil: buka index.html; navbar dan hero sudah tampil dengan tema gelap.

6

Menyiapkan Data Paket

Seluruh isi paket disimpan di data.js. Mengubah harga atau menambah paket cukup dengan mengedit berkas ini; kode lain tidak perlu disentuh.

  • WA: nomor WhatsApp tujuan (format internasional tanpa +, mis. 6281234567890).
  • D: daftar paket. c kode, n nama, tag keterangan, r revisi, lo dan hi harga terendah dan tertinggi, p teks harga, s lingkup kerja, o hasil akhir, src (1 bila source code termasuk).
  • X: biaya tambahan, yaitu source code 30% serta revisi minor dan major.
Jika mengubah harga, ubah juga p (teks) dan lo/hi (angka) agar tampilan dan estimasi tetap sama.

7

Menampilkan Paket dengan JavaScript

main.js membangun HTML kartu dan baris tabel dari data D, lalu memasukkannya ke halaman. Menambah paket di data.js otomatis menambah kartu.

  • Buat helper kecil: $ untuk memilih elemen, fmt untuk harga singkat, wa untuk tautan WhatsApp.
  • Tulis card(d) untuk tampilan Grid dan row(d) untuk tampilan Tabel.
  • Isi #g dan #tb dengan D.map(...).join("").
  • Pasang tautan WhatsApp konsultasi pada tombol di navbar, hero, dan banner.
Hasil: tiga kartu paket muncul lengkap dengan harga dan daftar lingkup.

8

Tampilan Grid, Tabel, dan Akordeon

Satu data bisa ditampilkan dua cara. Tombol Grid dan Tabel hanya menyembunyikan salah satunya, sedangkan akordeon “Hasil akhir yang diterima” memakai elemen bawaan <details> sehingga tidak butuh JavaScript.

  • Tambahkan bagian #paket ke HTML (tombol Grid/Tabel, #g, dan #t).
  • Tambahkan CSS grid tiga kolom dan gaya kartu.
  • Letakkan akordeon tepat di atas tombol agar sejajar antar kartu.
  • Tulis satu baris JavaScript untuk berpindah tampilan.

9

Memilih Paket dan Bar Estimasi

Paket yang dipilih disimpan dalam Map bernama sel (kode paket → jumlah proyek). Setiap perubahan memanggil upd() yang memperbarui tombol dan menampilkan bar di bawah layar.

  • Tambahkan markup bar #est dengan tombol “Lihat estimasi”.
  • Tambahkan CSS bar mengambang yang meluncur masuk saat ada paket.
  • Beri atribut data-c pada tombol “Tambah ke estimasi”.
  • Tangani klik: tambah bila belum ada, hapus bila sudah ada.
Hasil: menekan “Tambah ke estimasi” mengubah tombol menjadi “✓ Dalam estimasi” dan memunculkan bar.

10

Membuat Panel Estimasi

Panel di sisi kanan menampilkan rincian: daftar paket dengan jumlah proyek, opsi source code, revisi tambahan, subtotal, dan total. Panel dibuka dengan kelas open pada #dr dan lapisan gelap #ov.

  • Tambahkan markup #ov dan #dr.
  • Tambahkan CSS panel: posisi tetap di kanan, bergeser masuk dengan transform.
  • Tulis openDr() dan closeDr() yang juga mengatur fokus keyboard.
  • Tutup panel dengan tombol ×, klik lapisan gelap, atau tombol Esc.

11

Menghitung Estimasi

calc() menjumlahkan harga paket × jumlah proyek untuk batas bawah dan batas atas secara terpisah, lalu menambahkan source code (30%, hanya untuk paket tanpa source code) dan revisi tambahan.

  • Subtotal = Σ harga paket × jumlah proyek.
  • Source code = Σ harga × jumlah × 0,30 untuk paket dengan src = 0, bila dicentang.
  • Revisi minor = jumlah × Rp 50.000; revisi major = jumlah × Rp 200.000 (bawah) atau Rp 500.000 (atas).
  • Total = subtotal + source code + revisi minor + revisi major.
Contoh: Basic × 2 + source code + 1 revisi minor = Rp 310.000 – 1.350.000.

12

Menangani Semua Klik dengan Satu Pendengar

Alih-alih memasang pendengar pada setiap tombol, satu pendengar pada dokumen membaca atribut data-* dari elemen yang diklik. Cara ini tetap bekerja walau isi panel dibuat ulang.

  • data-c: tambah atau hapus paket. data-rm: hapus dari panel.
  • data-q: ubah jumlah proyek (1–99). data-ex: ubah revisi tambahan (0–99).
  • data-v: pindah Grid atau Tabel. #open, #close, #clr: buka, tutup, dan kosongkan.

13

Menyambungkan WhatsApp

Tombol WhatsApp hanyalah tautan https://wa.me/{nomor}?text={pesan}. Pesan disusun dari paket dan estimasi, lalu di-encode agar aman dimasukkan ke alamat.

  • Isi WA di data.js dengan nomor studio.
  • Gunakan satu fungsi wa(teks) untuk semua tombol.
  • Susun pesan sesuai jenisnya: konsultasi, pesan satu paket, atau estimasi.
  • Buka tautan di tab baru dengan rel="noopener".
Contoh pesan: “Halo, saya ingin memesan jasa pembuatan website dengan paket Basic. Estimasi harga: Rp 100.000 – 500.000.”
Bila WA masih kosong, WhatsApp hanya meminta pengunjung memilih kontak dan pesan tidak sampai ke studio.

Menguji Website

Uji setiap alur sebelum tayang. Buka konsol peramban (F12) untuk memastikan tidak ada galat berwarna merah.

  • Muat halaman: tiga kartu tampil dan bar estimasi tersembunyi.
  • Tambah Basic, buka panel, ubah jumlah menjadi 2, centang source code, tambah 1 revisi minor: total harus Rp 310.000 – 1.350.000.
  • Kosongkan estimasi: panel menutup dan bar hilang.
  • Tekan tombol WhatsApp: pesan terisi paket dan estimasi.
  • Cek lebar 1280 px dan 390 px, lalu coba tombol Esc dan Tab di keyboard.
Daftar skenario lengkap ada di BAB 6 dokumen SRS.

15

Menayangkan dan Memelihara

Karena statis, website cukup diunggah ke hosting statis. Setelah tayang, perawatan rutin hanya mengubah data.js, theme.css, dan logo.

  • Pilih hosting statis (Netlify, Vercel, GitHub Pages, atau hosting biasa) lalu unggah index.html, css/, js/, dan images/.
  • Pastikan HTTPS aktif dan uji semua tombol WhatsApp dari ponsel.
  • Ubah harga atau paket: edit data.js. Ubah warna atau font: edit theme.css. Ganti logo: timpa images/logo.png.
  • Simpan cadangan sebelum mengedit agar mudah dikembalikan.
