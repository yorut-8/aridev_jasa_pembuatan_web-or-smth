2. js/data.js - DATA YANG BISA DIEDIT
=====================================

WA
    Nomor WhatsApp tujuan semua tombol chat. Tulis dengan format internasional
    tanpa tanda +, contoh 6281234567890. Jika dikosongkan, WhatsApp akan
    meminta pengunjung memilih kontak sendiri.

D
    Daftar paket (Basic, Business, Professional). Setiap paket berisi:

    c       kode paket, contoh WB-01
    n       nama paket
    tag     keterangan singkat di bawah nama
    r       jatah revisi
    lo      harga terendah dalam rupiah (untuk hitung estimasi)
    hi      harga tertinggi dalam rupiah (untuk hitung estimasi)
    p       teks harga yang tampil di halaman
    s       daftar lingkup kerja (daftar centang)
    o       hasil akhir yang diterima
    src     1 = tampilkan lencana "Source code termasuk", 0 = sembunyikan

    Catatan: jika harga diubah, ubah juga p (teks) dan lo / hi (angka)
    agar estimasi tetap sesuai.

X
    Biaya tambahan di panel estimasi. Isi: src (n = nama, d = keterangan, pct
    = persentase tambahan, 0.3 = 30% khusus paket yang belum termasuk source
    code), minor dan major (n = nama, d = teks harga, lo / hi = harga terendah
    dan tertinggi per revisi dalam rupiah).


3. js/main.js - FUNGSI JAVASCRIPT
=================================

$(s)
    Singkatan dari document.querySelector. Dipakai untuk mengambil elemen
    halaman, contoh $("#g").

sel
    Map berisi kode paket yang sedang dipilih untuk estimasi beserta jumlah
    proyeknya (bukan fungsi, tetapi dipakai oleh fungsi-fungsi lain).

ex
    Pilihan tambahan di panel estimasi: src (1 = butuh source code), minor dan
    major (jumlah revisi tambahan).

fmt(n)
    Mengubah angka rupiah menjadi teks singkat. Contoh: 500000 menjadi "500
    rb", 1500000 menjadi "1,5 jt".

wa(t)
    Membuat link WhatsApp (wa.me) yang berisi nomor WA dan pesan t yang sudah
    di-encode.

ic
    Konstanta berisi ikon chat (SVG) untuk tombol tanya via WhatsApp di kartu.

chip(d)
    Mengembalikan lencana "Source code termasuk" jika paket d memiliki src =
    1; jika tidak, mengembalikan teks kosong.

card(d)
    Membuat HTML satu kartu paket untuk tampilan Grid: kode, nama, keterangan,
    harga, revisi, daftar lingkup kerja, akordeon "Hasil akhir yang diterima",
    tombol "Tambah ke estimasi", dan tombol chat WhatsApp.

row(d)
    Membuat HTML satu baris untuk tampilan Tabel: Kode, Layanan, Lingkup
    kerja, Hasil akhir, Revisi, Harga, dan tombol "+" untuk estimasi.

idr(n)
    Mengubah angka menjadi teks bertitik ribuan tanpa awalan Rp. Contoh:
    1500000 menjadi "1.500.000".

rng(a,b)
    Membuat teks rentang harga, contoh "Rp 100.000 - 500.000". Jika a sama
    dengan b, hanya satu angka yang ditampilkan.

calc()
    Menghitung estimasi: mengumpulkan paket terpilih (it), subtotal terendah
    dan tertinggi (sub), rincian biaya tambahan (ln: source code, revisi
    minor, revisi major; hanya yang nilainya lebih dari 0), lalu total (t)
    setelah semua biaya tambahan dihitung. Source code menambah 30% untuk
    paket yang belum termasuk source code.

stp(a,t)
    Membuat HTML pengatur jumlah "- teks +". Atribut a menentukan tombol itu
    milik siapa, dan t adalah teks di tengah (contoh "1 proyek").

panel(it)
    Membuat HTML isi panel estimasi: daftar paket dengan jumlah proyek dan
    harga, kotak centang "Butuh source code", serta pengatur revisi tambahan
    minor dan major.

Render awal (jalan sekali saat halaman dibuka)
    Mengisi #g (kartu) dan #tb (baris tabel) dari data D, memasang link
    WhatsApp konsultasi gratis ke tombol #wa0 (navbar), #wa1 (hero), dan #wa2
    (banner bawah), serta memberi ikon dan teks pada tombol #send di panel
    estimasi.

upd()
    Menyegarkan seluruh tampilan sesuai pilihan: (1) mengubah teks tombol
    estimasi di kartu dan tabel menjadi "Dalam estimasi" atau "Tambah ke
    estimasi"; (2) memanggil calc(); (3) menampilkan atau menyembunyikan bar
    estimasi #est dan mengisi jumlah layanan (#cnt) serta total (#tot); (4)
    mengisi panel: isi (#dbody), subtotal (#sub), baris rincian "Source code",
    "Revisi minor", dan "Revisi major" (#ext), serta estimasi total (#grand);
    (5) menyusun link WhatsApp pada tombol #send berisi paket, tambahan, dan
    estimasi harga, dan menonaktifkannya bila belum ada paket.

openDr() dan closeDr()
    Membuka panel estimasi (panel dan lapisan gelap diberi kelas open, fokus
    pindah ke tombol tutup) dan menutupnya (fokus kembali ke tombol
    sebelumnya).

Event klik (satu listener untuk seluruh halaman)
    Menangani semua klik: (1) tombol data-c menambah atau menghapus paket dari
    estimasi; (2) data-rm menghapus paket dari panel; (3) data-q mengubah
    jumlah proyek (1 sampai 99); (4) data-ex mengubah jumlah revisi tambahan;
    (5) data-v berpindah antara tampilan Grid (#g) dan Tabel (#t); (6) #open
    dan #open2 membuka panel; (7) #close atau lapisan gelap menutup panel; (8)
    #clr mengosongkan semua pilihan lalu menutup panel. Setiap perubahan
    memanggil upd().

Event change
    Saat kotak centang "Butuh source code" diubah, pilihannya disimpan ke
    ex.src lalu upd() dipanggil.

Event keydown
    Menutup panel estimasi saat tombol Esc ditekan.

upd() di baris terakhir
    Dipanggil sekali di akhir file agar bar estimasi mulai dalam keadaan benar
    (tersembunyi).


4. index.html - BAGIAN HALAMAN
==============================

  head                Judul halaman, pengaturan layar HP (viewport), font
                      Google (Plus Jakarta Sans dan Instrument Serif), dan
                      link ke css/theme.css serta css/style.css.
  nav                 Navbar yang menempel di atas: logo, link "Paket harga"
                      dan "Konsultasi", serta tombol WhatsApp #wa0.
  header.hero         Bagian pembuka: lencana, judul "Konsultasi gratis
                      bersama kami.", paragraf pengantar, tiga tombol (#wa1,
                      "Lihat paket harga", "Hitung estimasi proyek"), dan dua angka ringkas.
  aside.panel         Kartu di sisi kanan hero: rentang harga tiga paket.
  main#paket          Daftar harga: judul, jumlah layanan, tombol Grid /
                      Tabel, grid kartu (#g), dan tabel (#t dengan isi di
                      #tb).
  section#konsultasi  Banner ajakan konsultasi gratis (#wa2) dan teks footer.
  #est                Bar mengambang di bawah layar: jumlah layanan dipilih
                      (#cnt), total estimasi (#tot), dan tombol "Lihat
                      estimasi" (#open).
  #ov, aside#dr       Lapisan gelap dan panel estimasi di sisi kanan. Isi:
                      daftar paket (#dbody), subtotal (#sub), rincian biaya
                      tambahan (#ext), estimasi total (#grand), tombol "Kirim
                      estimasi via WhatsApp" (#send), "Kosongkan estimasi"
                      (#clr), dan tombol tutup (#close).
  script              Memuat js/data.js lebih dulu, baru js/main.js. Urutan
                      ini harus dipertahankan.

7. INTEGRASI BACKEND (OPSIONAL)
==============================

js/config.js
    Berisi API_BASE, alamat backend (kosong bila website dan backend satu
    alamat, contoh "https://api.domain-anda.com" bila terpisah). Bila backend
    tidak ada atau tidak dapat dihubungi, website tetap berjalan dengan data
    bawaan di data.js.

WA (data.js)
    Kini dideklarasikan dengan let agar dapat diganti oleh data dari backend.

render()
    Mengisi kartu (#g), baris tabel (#tb), baris harga pada hero (#hp), jumlah
    paket (#npk dan #nly), dan tautan WhatsApp konsultasi dari data D.
    Dipanggil sekali saat halaman dibuka dan sekali lagi setelah data dari
    backend diterima.

Pemuatan data backend
    Di akhir main.js, fetch ke API_BASE + "/api/packages" mengganti WA, D, dan
    X dengan harga terbaru dari panel admin, membuang paket terpilih yang
    sudah tidak ada, lalu memanggil render() dan upd(). Bila gagal, tidak
    terjadi apa-apa.

note(source, items)
    Mengirim pesan masuk ke API_BASE + "/api/inquiries" (jenis estimate, chat,
    atau consult) agar admin mendapat email. Dikirim di latar belakang dan
    tidak menghalangi pembukaan WhatsApp.

Event click tambahan
    Listener kedua pada dokumen: klik tombol #send memanggil note("estimate"),
    klik ikon chat kartu (a.ic dengan data-k) memanggil note("chat"), dan klik
    #wa0, #wa1, atau #wa2 memanggil note("consult").
